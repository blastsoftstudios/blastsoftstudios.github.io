Quickly sort or auto-sort Steam Games, add and edit non-steam shortcuts, and backup your vdf files.

How to Use:

  • To sort games either type the name of the group into the group textbox and press enter, or drag the game into the group on the right.
  • To add steam shortcuts drag the executable file onto the games and Steam App Buddy will automatically add it.
  • You can auto sort your games if you go to Edit>Auto Sort. This allows you to sort your games into different categories.
    • When auto-sorting by genre a dialog box will appear asking which genres to sort by. Leave this dialog box blank in order to sort by every genre.
    • You can combine different genres to sort only games that are both genres.
